跑测试并处理失败。测试范围（为空则跑全部）：$ARGUMENTS

1. 先确认本仓库的测试入口：没有 Makefile 也没有 CI，就是 `go test ./...`；单个包用 `go test ./internal/<包>/`，单个用例加 `-run`。
2. 跑起来，看真实输出，不要凭猜测判断结果。
3. 失败时按根因定位：读错误信息、读被测代码、检查断言是不是在测该测的东西。不要为了让测试变绿而改断言迁就实现。
4. 修完重跑，直到真的绿。
5. 如实汇报：失败就说失败并附上输出；绝不在输出明显有失败时声称「全部通过」。
